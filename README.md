A brand-new, cinematic 3D developer portfolio engineered from scratch. Specially positioned for offering custom website design and high-conversion development services to established roofing and remodeling contractors in the United States.

- **Cinematic 3D Hero Scene**: Deep charcoal theme (`#09090b`) with warm amber/orange lighting, atmospheric WebGL particle embers, and subtle camera parallax.
- **Floating Perspective 3D Website Mockup**: Real-time perspective-tilted browser mockup displaying *Apex Ridge Roofing & Remodeling* with interactive 3D mouse tilt, specular glare, instant quote form, and floating z-depth callout badges.

- **Authentic About Section**: Verified developer background for Fazil Shaik, direct communication model, and specialized value proposition.
- **Comprehensive Contractor FAQ**: Scope, $2,500 transparent pricing, 2–3 week turnaround, mobile compatibility, and ongoing maintenance.
- **Conversion-Optimized Contact Funnel**: Interactive inquiry form with input validation, budget ranges, copy-to-clipboard email trigger, and preformatted mailto fallback.

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## Stack

- **Framework**: React 18 + Vite 6
- **Styling**: Tailwind CSS + Custom 3D CSS Perspectives
- **3D Rendering**: Three.js (WebGL atmospheric particle field and perspective grid)
- **Icons**: Lucide React
- **Deployment Ready**: Optimized for Vercel, Netlify, or AWS Amplify
